## Project Overview

ARIMEN Tracksuits is a responsive e-commerce website developed as part of my Web Development module. The website allows users to browse premium tracksuits, view product details, select different sizes, add products to the shopping cart, update quantities, remove items, and view the total cost.

The project demonstrates the use of HTML, CSS, and JavaScript to create an interactive and user-friendly online shopping experience.

---

## Features

- Responsive homepage
- Product listing page
- Product details page
- Product search functionality
- Size selection
- Add to Cart
- Shopping cart
- Increase and decrease item quantity
- Remove items from the cart
- Automatic total price calculation
- Wishlist page
- Contact page
- About page
- Responsive layout for different screen sizes

## JavaScript Functionality

The JavaScript provides the interactive features of the website, including:

- Displaying products
- Product search
- Loading product details
- Size selection
- Adding products to the cart
- Saving cart data using Local Storage
- Updating item quantities
- Removing products from the cart
- Calculating the total price
- Displaying an empty cart message when no items are added
